# Assentia — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Departmental service owner

- As a service owner, I want to know before I commit to a supplier whether my intended decision service can meet the explanation standard for its consequence grade, so that I do not build something I will not be permitted to operate.
- As a service owner, I want the warrant to state plainly which evidence is missing and when it expires, so that I can plan remediation inside my budget year rather than discover a block at go-live.
- As a service owner, I want a warrant that survives a machinery-of-government change by requiring revalidation, so that a transferred service does not quietly operate under someone else's lapsed assurance.
- As a service owner, I want to see the challenges other departments have published, so that I can reuse an assured pattern instead of running a fresh procurement for the same problem.

### Commercial and category manager

- As a category manager, I want every challenge published on an open board before I go to market and SME participation reported by contract value as well as by count, so that domestic SMEs can see the requirement early instead of meeting a tender pre-shaped by incumbents, and so that I can tell genuine SME access from a token sub-contract.
- As a category manager, I want prototype and proof-of-concept spend held in a declared portfolio with an agreed failure tolerance, so that a prototype that does not proceed is recorded as a portfolio outcome and not as a procurement error.
- As a category manager, I want to be blocked from awarding a lot that depends on supplying a public dataset for which no valuation has been recorded, so that value leaves the department only on documented terms.

### Caldicott Guardian and data protection officer

- As a Caldicott Guardian, I want a single register of every agreement supplying patient data to a supplier, with the anonymisation approach, the opt-out treatment and the recorded value, so that our trust never again strikes a local deal that cannot be defended publicly.
- As a data protection officer, I want the evidence pack to hold the impact assessment, the lawful basis and the equality assessment as versioned records tied to the warrant, so that a disclosure request can be answered from the file rather than from memory.
- As a Caldicott Guardian, I want to refer a significant data supply agreement to external review before signature and see that outcome recorded, so that the review is a gate rather than an opinion.

### Redress caseworker

- As a redress caseworker, I want to retrieve the explanation for a specific decision as it stood on the day it was taken, so that I can answer a complaint without asking the supplier to reconstruct it.
- As a redress caseworker, I want to open a challenge that is time-boxed and escalates automatically if unresolved, so that a citizen's contest has a deadline rather than a queue.
- As a redress caseworker, I want to record when a decision is overturned and the reason, so that a pattern of overturns becomes visible as evidence against the service's warrant rather than as scattered casework.

### Assurance and audit lead

- As an assurance lead, I want to suspend a warrant when the ethical-code seal is withdrawn and have live operation stop as a consequence, so that conformance has an operational effect instead of a reputational one.
- As an assurance lead, I want an annual return built on the same definitions every year and comparable with named international jurisdictions, so that a change of administration does not reset the baseline against which we report to Parliament.
- As an assurance lead, I want the assurance and regulator workload generated by the portfolio measured and published, so that when oversight capacity is being funded the true cost of oversight is on the table.
